# fedeinfe.github.io

Esiste per un file solo: `app-ads.txt`, che AdMob cerca alla radice dell'host del sito sviluppatore
indicato nelle schede di store di RottenPDF. Il sorgente è `store/app-ads.txt` nel repo dell'app.

`etuner/` contiene la pagina di eTuner, l'assistenza (`support/`) e l'informativa sulla privacy (`privacy/`); i sorgenti sono `store/site/` e `store/privacy-policy/` nel repo dell'app.
